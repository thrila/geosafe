What does /upload do?

Accepts a video file + a DJI .txt flight log, runs the video through the crop-disease detection pipeline (frame extraction → quality check → tiling → ML inference → save), then enriches the result with telemetry data from the SQLite database (GPS track, battery, speed, altitude) and returns a unified JSON response.

Request multipart/form-data

POST /api/v1/upload Content-Type: multipart/form-data name : string — flight/survey name video : file — .mp4, .avi, .mov, .mkv log : file — .txt DJI flight log

Video Processing Pipeline click each step

1 — Frame Extraction (Sampler) ▾
sampler.py → frame_iterator()
Opens the video with cv2.VideoCapture and yields frames at the target FPS (default 5). This is sequential — OpenCV's VideoCapture is not thread-safe, so a single producer thread reads frames one by one and pushes them into a shared queue.

Key config: fps=5.0 — a 30fps, 60s video produces ~300 frames.
2 — Quality Gate ▾
quality.py → check_quality()
Computes grayscale once, then runs two checks:
• Blur: Laplacian variance < 100 → reject
• Brightness: mean < 30 or > 230 → reject

Rejects frames early to avoid wasting inference time on bad imagery.
3 — Tiling ▾
tiler.py → tile_frame()
Splits each 1920×1080 frame into 640×640 tiles with 10% overlap. A single frame produces ~8 tiles. Each tile is an independent numpy array (.copy()) so workers can process them in parallel without data races.

Why? The ML models expect 640×640 (plant) or 380×380 (disease) input.
4 — ML Inference (Two-Stage Cascade) ▾
inference.py + onnx_backend.py

Stage A — Plant Classification (per-tile, singular):
• Model: YOLOv8 ONNX, 640×640 input
• Classes: cassava, plantain, unknown
• ONNX has fixed batch dim=1, so tiles are classified one at a time

Stage B — Disease Classification (batched by plant class):
• Model: EfficientNet-B0 ONNX, 380×380 input
• Cassava: CBB, CBSD, CGM, CMD, Healthy (5 classes)
• Banana: AugmentedSet, OriginalSet (2 classes)
• predict_batch() groups tiles by plant class and runs them together
• Confidence < 0.5 → overridden to "Healthy"
5 — Persist + Aggregate ▾
saver.py + flights.py (service)

• Diseased tiles saved as JPEG to output/images/
• JSON metadata saved to output/metadata/
• Slides built from frames with image_url (diseased frames only)
• Slides + flight metadata written to SQLite
• Telemetry aggregated: max speed, height, battery, GPS, route distance
• Final JSON response assembled by FlightService

Three Layers of Concurrency

Layer 1 Request Level

  • FastAPI routes are async def — non-blocking
  • CPU work offloaded via run_in_threadpool
  • Multiple uvicorn workers in production (--workers 4)
  • Each request gets its own temp directory

Layer 2 Video Processing

  • Producer-consumer pattern with ThreadPoolExecutor
  • 1 producer thread: reads frames sequentially (cv2 constraint)
  • N worker threads: quality → tile → infer → save
  • Configurable: max_workers=4, batch_size=8

Layer 3 ONNX Inference

  • ONNX sessions are thread-safe for concurrent run()
  • intra_op_num_threads=2 per session prevents oversubscription
  • Disease model: true batch inference via predict_batch()
  • Plant model: fixed batch dim=1, falls back to singular

Safety Thread Safety

  • Model loading: double-checked locking with threading.Lock
  • Bench accumulator: thread-safe append()
  • Each video writes to its own temp dir — no cross-request conflicts
  • Tile arrays are .copy()’d — no shared mutable state

Producer-Consumer Pattern

# pipeline/inference.py — simplified def process_video(self, video_path, out_dir): with ThreadPoolExecutor(max_workers=4) as pool: futures = [] # Producer: read frames sequentially (cv2 is not thread-safe) for frame, ts in sampler.frame_iterator(video_path): futures.append(pool.submit(_process_frame_batch, frame, ts)) # Wait for all workers, collect results results = [f.result() for f in as_completed(futures)] return _aggregate(results) def _process_frame_batch(self, frame, timestamp): # Each worker thread runs this independently: quality = check_quality(frame) # shared-nothing tiles = tile_frame(frame) # .copy() per tile plants = plant_model.predict(tiles) # singular ONNX diseases = disease_model.predict_batch( # batch ONNX group_by_plant(tiles, plants)) save_diseased(tiles, diseases) # disk I/O return frame_result

Where Each Field Comes From

From DB TelemetryRepository

  • flight.id, name, start_ts, end_ts
  • telemetry.latitude, longitude, height
  • telemetry.x_speed, y_speed, z_speed
  • telemetry.battery_level, battery_temp, gps_num

Computed FlightService

  • maxSpeedMs — sqrt(x²+y²+z²) max
  • routeDistanceKm — haversine sum
  • batteryDrainedPct — start − end
  • duration — (end−start)/1000 formatted

From Pipeline process_video()

  • per_frame_results[].prediction
  • per_frame_results[].image_url
  • diseasesDetected — unique non-healthy

Built build_slides()

  • slides[].kind — always "image"
  • slides[].src — from image_url
  • slides[].caption — "Frame N — Disease"
